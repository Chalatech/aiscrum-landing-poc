Cómo funciona

1. Grafo, no columnas

Las tareas tienen dependencias explícitas. Un agente pregunta aiscrum ready en vez de que un humano arrastre tarjetas.

2. Git es la base de datos

El estado vive en un JSONL versionado. Revertir un commit revierte también el estado del trabajo.

3. Evidencia, no un booleano

Cerrar una tarea exige adjuntar evidencia: un PR, un test run, un trace id. "Done" sin evidencia no cuenta.
